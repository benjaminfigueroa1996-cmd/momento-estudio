# Plantillas de correo de Supabase (en español, con la marca)

Se pegan en Supabase > Authentication > Emails > Templates. Cada plantilla tiene un asunto y un cuerpo (pestaña Source).

- **1-restablecer-contrasena.html** · Asunto: `Restablece tu contraseña · Momento Estudio`
- **2-enlace-de-acceso.html** · Asunto: `Tu enlace de acceso · Momento Estudio`
- **3-invitacion.html** · Asunto: `Te invitaron a Momento Estudio · Momento Estudio`
- **4-confirmar-cuenta.html** · Asunto: `Confirma tu correo · Momento Estudio`
- **5-cambio-de-correo.html** · Asunto: `Confirma tu nuevo correo · Momento Estudio`

Correspondencia en Supabase: 1 = Reset Password, 2 = Magic Link, 3 = Invite user, 4 = Confirm signup, 5 = Change Email Address.

El remitente seguirá siendo de Supabase hasta configurar SMTP propio (por ejemplo, Resend con el dominio momentoestudio.cl).
